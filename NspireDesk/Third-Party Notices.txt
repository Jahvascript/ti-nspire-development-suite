- libusb1-sys 0.4.4, MIT wrapper with bundled libusb under LGPL-2.1-or-later.

  https://github.com/a1ien/rusb
  https://libusb.info/

Other Rust dependencies and exact versions are listed in backend/Cargo.lock.
The GitHub source repository excludes the large local source/vendor/ cache.
Run source/backend/bootstrap-rust-deps.sh once with internet access to
download locked dependencies and generate a local Cargo vendor configuration.
Subsequent builds can run offline. Modified patched dependencies and their
available upstream notices remain in source/patches/. Distributors of
compiled releases must also satisfy applicable GPL/LGPL corresponding-source
and license obligations.
